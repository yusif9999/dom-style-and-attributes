# Seasonal Drink & DOM Attributes Practice

A dynamic web application that suggests a seasonal beverage based on the current month. This project was built specifically to practice core JavaScript DOM manipulation techniques.

## Focus Areas
This project demonstrates the practical application of the following DOM concepts:
* **DOM Selectors:** Using `querySelector` to target and access HTML elements.
* **Content Manipulation:** Dynamically updating page text using the `.textContent` property.
* **Inline Styling:** Altering element styles directly via the `.style` property (e.g., dynamic background colors and image dimensions).
* **Attribute Manipulation:** Utilizing `.setAttribute()` to dynamically change image sources (`src`) based on the calculated season and randomly selected drink.

## How It Works
The script checks the current month using the JavaScript `Date` object, determines the current season, and randomly selects a drink and its corresponding image from predefined arrays. It then updates the DOM elements, applying specific background colors and image attributes that match the seasonal theme.
